# Bigotti Catalog

Bigotti Catalog is an internal web application for the Bigotti online sales team.

The goal is to help sellers quickly find products by reference, name, type, color, size, price, and tags.

## Tech Stack

- Frontend: Next.js, TypeScript, Tailwind CSS
- Backend: NestJS, GraphQL, Prisma
- Database: PostgreSQL on Supabase
- Authentication: JWT
